# Beacon Learn — Ứng Dụng Tự Học & Luyện Thi THPT

Ứng dụng web tự học chuyên biệt dành cho học sinh THPT với giao diện máy tính chuẩn, hỗ trợ phong cách **Dark Mode (Aurora Glass)** và **Light Mode (Liquid Glass)**, cùng các tính năng:
- **Trang chủ & Thống kê học tập**: Theo dõi tiến độ học tập hàng ngày, chuỗi ngày học (streak) và điểm kinh nghiệm (XP).
- **Thời khóa biểu ma trận**: Bảng lịch học trực quan theo ngày trong tuần, có thể tùy chỉnh thêm bớt khung giờ theo nhu cầu.
- **Không gian học tập & Bài tập về nhà**: Quản lý môn học, checklist bài tập và ghi chú nháp nhanh.
- **Thẻ ghi nhớ 3D (Flashcard)**: Ôn tập kiến thức với hiệu ứng lật thẻ 3D và phím tắt tiện lợi.
- **Luyện đề & Trắc nghiệm**: Bộ câu hỏi trắc nghiệm tính giờ kèm lời giải chi tiết.
- **Đồng hồ Pomodoro**: Bộ đếm thời gian tập trung 25/5/15 phút kèm âm thanh thư giãn.
- **Trò chơi học tập**: Ghép thẻ công thức và hệ thống huy hiệu pha lê vinh danh.

## Cài đặt & Khởi chạy

```bash
# Cài đặt thư viện
npm install

# Khởi chạy môi trường phát triển
npm run dev

# Đóng gói sản phẩm
npm run build
```
